# Slack Provider

Manage Slack Apps as Code with Terraform and OpenTofu through Slack's public Manifest API.

Set `SLACK_APP_CONFIGURATION_TOKEN` to a Slack app configuration access token. Configuration tokens expire after 12 hours; rotate them outside Terraform and persist both rotated tokens. Ordinary bot and Socket Mode tokens are not configuration tokens.

```terraform
terraform {
  required_providers {
    slack = {
      source = "registry.opentofu.org/solcreek/slack"
    }
  }
}

# Supply SLACK_APP_CONFIGURATION_TOKEN through your environment.
provider "slack" {}
```

## State and ownership

The `slack_app` resource owns the complete app manifest. Updates replace the entire configuration, and destroy permanently deletes the app. App installation and OAuth exchanges are separate operations. Scope changes may require reinstalling the app.

Creation secrets are sensitive but persist in state. Use an encrypted, access-controlled backend. Import cannot recover credentials, and external credential rotation is not detectable through manifest export.
